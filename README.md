# Waybill System 🚀

Full-stack logistics platform with:

- Waybill generator
- PDF download
- Notifications (Email, SMS, WhatsApp)
- Admin dashboard (JWT auth)
- Mobile app (React Native)

## Run locally

### 1. Start backend
cd backend
npm install
npm run dev

### 2. Start notification service
cd notification-service
npm install
npm run dev

### 3. Start frontend
cd frontend
npm install
npm start

### 4. Start mobile
cd mobile
npm install
npx expo start
